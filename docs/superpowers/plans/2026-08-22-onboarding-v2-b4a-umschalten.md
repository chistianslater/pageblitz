# Onboarding v2 — Plan B4a „Umschalten & Absichern" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Das Produkt läuft vollständig auf v2 — StartPage → Studio, Generierung immer v2, Studio als Post-Checkout-Editor, schlankes Dashboard, Landingpage-Showcase mit Style Packs, Legacy-URLs umgeleitet — **ohne** in diesem Plan schon Alt-Code zu löschen (das macht B4b auf sicherer Basis).

Jede Aufgabe lässt das System lauffähig.

**Tech Stack:** wie B1–B3. **Spec:** `docs/superpowers/specs/2026-08-22-cutover-design.md` (+ Spec B §7, Inventar `.superpowers/b4-inventar.md`).
